# 简历管理与岗位匹配页优化实现计划

> **面向 AI 代理的工作者：** 按任务边界协作实现，行为变更遵循测试先行；不要提交或推送 Git。

**目标：** 完成受控简历条件、单简历增量匹配、完整结果展示和结果优先的匹配页视觉升级。

**架构：** 保留现有 FastAPI、SQLite、Vue 单页结构。后端扩展现有匹配请求与岗位快照逻辑，前端在现有页面内部重新排列控制区、轨迹与结果，不重写模块。

**技术栈：** Python 3.12、FastAPI、SQLite、Vue 3、原生 CSS、pytest。

---

### 任务 1：简历条件下拉

- [ ] 获取并落地上游城市数据。
- [ ] 为城市、经验、学历、薪资增加受控选项。
- [ ] 保持现有保存接口与默认值兼容。
- [ ] 增加必要测试并验证。

### 任务 2：匹配增量链路

- [ ] 先写测试覆盖指定简历匹配、岗位内容变化、完整结果和刚刚活跃筛选。
- [ ] 扩展匹配请求以接收简历 ID。
- [ ] 为岗位保存可比较的内容快照或指纹。
- [ ] 仅评分新岗位或内容变化岗位，移除结果 Top 10 截断。
- [ ] 返回并持久化原始活跃状态。
- [ ] 运行后端测试验证。

### 任务 3：结果优先匹配页

- [ ] 将简历选择和匹配按钮放入紧凑控制栏。
- [ ] 未选择简历时禁用按钮，完成后切换为“继续匹配”。
- [ ] 将五阶段任务轨迹压缩成匹配信号轨。
- [ ] 优化下拉、标签页和结果卡视觉，展示精细活跃状态。
- [ ] 移除界面中的 Top 10 文案与计数上限。
- [ ] 验证键盘焦点、移动端和减少动效设置。

### 任务 4：集中验收

- [ ] 对照全部需求做一次集中检查并直接修复缺口。
- [ ] 运行完整 pytest 与 ruff。
- [ ] 启动本地页面，验证主要交互并检查控制台。
